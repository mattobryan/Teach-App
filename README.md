# Teach · Français — Android app

Download: [teach-francais.apk](teach-francais.apk) (Android 8.0+, about 20 MB)

Version 0.2.1 (build 101), built from [mattobryan/Teach](https://github.com/mattobryan/Teach) branch `matt/kotlin-android`.

## Install

1. On your phone, open this page and download `teach-francais.apk`.
2. Open it and allow installs from your browser when Android asks.
3. If an older Teach build is installed, uninstall it first: this build uses the permanent signing key, so later builds install over it. Export your progress in Settings before uninstalling.

## What's in it

- Guided voice lessons: the tutor speaks, listens, grades on the phone and explains. No AI tokens.
- Free conversation with Claude (needs your Anthropic API key in Settings).
- The audio-reactive voice orb, progress tracking and automatic French-first / French-only modes.
